## Lustige Witzige Erlebnisse

### The Stitch/Shirt Incident

Source: `OuroborosCollective/Wasd`, `docs/lore/STITCH_SHIRT_INCIDENT.md`.

During a late mobile development session, the intended instruction was effectively: "Stitch MCP, cut the assets out and import them into the game." Phone autocorrection transformed Stitch into Shirt. The agent interpreted this as a cosmetic shirt import, produced shirt assets, renamed workflow pieces, opened pull requests, merged and deployed before the correction arrived. The resulting fictional collection was named the "Areloria Warfront Summer Collection".

The incident is valuable because it combines affection, absurdity and a real engineering lesson: import is not slicing, autonomous agents require review gates, and funny legacy names should be documented before they are removed.

Suggested historical flavor line preserved from the source:

> Born from Stitch. Deployed as Shirt.
