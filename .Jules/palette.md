## 2025-05-18 - Label in Name and Keyboard Affordance in Dark-Themed Side Panels
**Learning:** Overriding action buttons with extended `aria-label` values (e.g. `aria-label="Draft PR öffnen: https://..."` when visible text is `"Draft PR öffnen"`) breaks WCAG 2.5.3 (Label in Name), hindering voice-control speech recognition and screen reader label consistency. In dark-themed compact panels like `WorkbenchSidePanel`, action controls need explicit `focus-visible:ring-2` styling, hover transitions, and decorative indicator dots require `aria-hidden="true"`.
**Action:** Always preserve the visible text as the accessible name by omitting redundant or conflicting `aria-label` overrides, deliver contextual details via the native `title` attribute, mark decorative indicator dots with `aria-hidden="true"`, and apply `focus-visible:ring-2 focus-visible:outline-none transition-opacity hover:opacity-90` to all action buttons in side panels.
