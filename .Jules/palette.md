## 2025-05-18 - Semantic Lists and Accessible Landmarks in Complex Diagnostic Grids
**Learning:** Diagnostic breakdown panels (such as `ErrorCategoriesPanel`) that render severity metrics and category findings often use non-semantic `div` grids. Screen readers fail to announce list boundaries or item counts when items are plain `div` elements, making keyboard navigation and assistive technology overview orientation difficult. Furthermore, using `aria-label` on sections with visible headers creates redundant or detached screen reader landmarks.
**Action:** Always link landmark containers to visible heading IDs via `aria-labelledby`. Convert breakdown grids and nested lists into `<ul role="list">` and `<li>` elements with descriptive `aria-label` attributes to ensure screen readers provide clear structure, item count announcements, and natural list navigation.
